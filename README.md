# python---automacao
Esse projeto foi feito com o objetivo de aprender e praticar automação usando Python, simulando um controle de estoque simples.

A ideia principal é:

Ler um arquivo Excel com produtos e quantidades

Ver automaticamente quais produtos estão abaixo do estoque mínimo

Gerar um relatório em PDF com essas informações

Servir como base para estudos futuros (Power BI, interfaces, automações maiores)

💡 O que esse projeto faz

Lê um arquivo estoque.xlsx

Analisa os dados usando Python

Identifica produtos em falta

Gera um relatório em PDF automaticamente

Organiza os relatórios em uma pasta

Funciona mesmo com muitos produtos (50+)

Tudo isso sem precisar editar nada manualmente depois que o Excel está pronto.

🛠️ Tecnologias usadas

Python

Pandas (para ler e tratar o Excel)

ReportLab (para gerar o PDF)

Excel

Power BI (ideia futura para visualização dos dados)
